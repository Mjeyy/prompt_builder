# Prompt Builder

Утилита для сборки промптов по ремонту, тюнингу, поиску ссылок и шуточному автогороскопу.

**Полный ранбук** (установка, запуск, разбор поломок): [RUNBOOK.md](RUNBOOK.md).  
Как менять код и документацию: [CONTRIBUTING.md](CONTRIBUTING.md).  
История изменений: [CHANGELOG.md](CHANGELOG.md).

Два способа запуска:

- **Терминал** — интерактивное меню, готовый промпт сразу копируется в буфер обмена macOS. Текст промпта в терминал **не выводится**.
- **Визуальный интерфейс** — сборка промпта с превью, поиск ссылок, гороскоп (описание авто и прогноз по датам), список автомобилей (что показывать в ремонте и тюнинге) плюс проверка markdown-таблиц: в поле `summary` должно быть ровно 4 абзаца, разделённых `<br><br>`.

## Что делает утилита

1. Загружает список автомобилей из `data/autos.md`.
2. Загружает шаблоны из `data/repair_prompts.md` (ремонт), `data/tuning_prompts.md` (тюнинг), `data/links.md` (поиск ссылок), `data/horoscope_auto.md` и `data/horoscope_date.md` (гороскоп).
3. Для ремонта и тюнинга подставляет `make`, `model`, `generation`, `engine` вместо `[MAKE]`, `[MODEL]`, `[GENERATION]`, `[ENGINE]`.
4. Для поиска ссылок и гороскопа подставляет марку и модель вместо `[МАРКА]`, `[МОДЕЛЬ]`; в прогнозе ещё `[ДАТА_НАЧАЛА]` (включительно) и `[КОЛИЧЕСТВО_ДНЕЙ]`.
5. Копирует готовый промпт в буфер через `pbcopy` (в терминале — сразу после выбора; в окне — только по кнопке).
6. В окне — открывает локальные MD-таблицы, находит ошибки в `summary` и правит их в копии `*_fix.md`, не трогая исходник.

## Требования

- macOS (`pbcopy`)
- Python 3.10 или новее
- Для **окна** — Tk: `python -c "import tkinter"` должен работать
- Git — если клонируете репозиторий

Пошаговая установка с проверками: [RUNBOOK.md](RUNBOOK.md).

## Быстрый старт

```bash
cd /путь/к/prompt_builder-master
```

Создайте окружение на Python, у которого есть Tk (часто это `/usr/local/bin/python3.11` с python.org, а не Homebrew 3.14):

```bash
/usr/local/bin/python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Голый `pip` не используйте — на macOS он может вызвать системный `/opt/homebrew/bin/pip` со сломанным интерпретатором.

Запуск:

```bash
python -m prompt_builder          # терминал
python -m prompt_builder.gui      # окно
```

или после активации `.venv`: `prompt-builder` / `prompt-builder-gui`.

Остановка: в терминале **Выход** или `Ctrl+C`; окно — закрыть. Из venv: `deactivate`.

## Как работать в терминале

После запуска — меню (стрелки ↑↓ и Enter).

1. Авто из `data/autos.md`, например `Chevrolet Tahoe · GMT K2XX · L86`. В списке первая строка меняет порядок: как в файле или по алфавиту (марка, модель, поколение, мотор).
2. Категория: **Ремонт**, **Тюнинг**, **Поиск ссылок**, **Гороскоп: описание авто** или **Гороскоп: прогноз**.
3. Для ремонта и тюнинга — раздел, например `ENGINE — Двигатель и топливная система`.
4. Для прогноза — дата начала (сегодня и ближайшие 13 дней или ввод в формате `ГГГГ-ММ-ДД`) и число дней: **7** (по умолчанию), **10**, **30** или вручную.

Отчёт (ремонт / тюнинг):

```text
✓ Промпт скопирован в буфер обмена

  Авто:       Chevrolet Tahoe · GMT K2XX · L86
  Категория:  Ремонт
  Раздел:     ENGINE — Двигатель и топливная система
```

Вставка в нейросеть: `Cmd+V`.

| Действие | Что происходит |
|----------|----------------|
| **Повторить** | Снова копирует тот же промпт |
| **Другой раздел** | Другой раздел, то же авто и категория (только ремонт / тюнинг) |
| **Другая категория** | Ремонт / тюнинг / поиск ссылок / гороскоп, то же авто |
| **Сменить авто** | Сначала выбор автомобиля |
| **Выход** | Выход |

## Визуальный интерфейс

Запуск: `python -m prompt_builder.gui`. На главном экране шесть режимов.

### Сборка промпта

1. Найдите и выберите авто. Порядок списка: **Как в файле** (как строки в `data/autos.md`) или **По алфавиту**. Скрытые в «Списке автомобилей» позиции сюда не попадают.
2. Категория: **Ремонт** или **Тюнинг**.
3. Раздел.
4. Превью обновляется сразу; текст в превью можно выделять. В буфер — только **Скопировать в буфер**.

Другое авто, категорию или раздел выбирайте кликом в списках.

### Поиск ссылок

1. Найдите и выберите авто. В списке — уникальные пары марка + модель (скрытые для ремонта/тюнинга здесь всё равно видны). В промпт уходят только марка и модель.
2. Порядок списка: **Как в файле** или **По алфавиту**.
3. Превью обновляется сразу. В буфер — только **Скопировать в буфер**.

### Гороскоп: описание авто

1. Найдите и выберите авто. Список — уникальные марка + модель, без учёта скрытия. В промпт уходят только марка и модель.
2. Порядок: **Как в файле** или **По алфавиту**.
3. Превью обновляется сразу. В буфер — только **Скопировать в буфер**.

### Гороскоп: прогноз

1. Выберите авто (уникальные марка + модель, без учёта скрытия).
2. Дату старта — в календаре (день входит в прогноз) или кнопкой **Сегодня**.
3. Число дней: **7** (по умолчанию), **10**, **30** или **Вручную**.
4. Превью обновляется сразу. В буфер — только **Скопировать в буфер**.

### Список автомобилей

Только в окне. Показывает все строки `data/autos.md` и статус «Видно» / «Скрыто». Переключатель сразу пишет в `data/autos_hidden.md`. Каталог `data/autos.md` не меняется. Скрытие действует только на сборку ремонта и тюнинга.

### Проверка таблиц

Только в окне. Нужен `.md` с таблицей и колонкой `summary` (образцы в `docs/samples/`).

Ошибка: в `summary` не ровно 4 абзаца через `<br><br>`.

1. **Открыть файл** — исходник только читается.
2. Видно число ошибок.
3. **Режим редактирования** создаёт `имя_fix.md` в той же папке.
4. Правки по очереди: строка, статья (`topic_title`), текст `summary`. Пустая строка в редакторе = `<br><br>`.
5. **Сохранить и далее** пишет в `*_fix.md`. Если абзацев не 4 — дальше не пускает.
6. **Пропустить** / **Назад** / **К результатам** — очередь можно обойти или прервать без потери файла.
7. **Повторить сканирование** проверяет копию. Цель — **0 ошибок**.

## Как обновлять данные

Правите markdown в папке `data/`, код трогать не нужно. После сохранения перезапустите программу.

### Авто (`data/autos.md`)

```markdown
| make | model | generation | engine |
|------|-------|------------|--------|
| Chevrolet | Tahoe | GMT K2XX | L86 |
```

Новая строка в конец таблицы. Колонки не переименовывать. Больше никуда писать не нужно: новая позиция сразу видна. В `data/autos_hidden.md` она появится, только если её скрыть в окне («Список автомобилей»).

В окне гороскоп и поиск ссылок показывают уникальные пары марка + модель: другой мотор или поколение той же марки и модели отдельной строкой там не станет.

### Скрытие авто (`data/autos_hidden.md`)

Только скрытые позиции (те же четыре колонки). Пустая таблица — ничего не скрыто. Файл пишет GUI; вручную править не обязательно. Записи, которых нет в `autos.md`, игнорируются.

### Ремонт (`data/repair_prompts.md`)

```markdown
### 1. ENGINE — Двигатель и топливная система (Repair)

```text
текст с [MAKE], [MODEL], [GENERATION], [ENGINE]
```
```

### Тюнинг (`data/tuning_prompts.md`)

Заголовок `## N. ID — Название` **без** `(Repair)`, внутри — блок ` ```text `.

### Гороскоп (`data/horoscope_auto.md`, `data/horoscope_date.md`)

Целые файлы — шаблоны. Плейсхолдеры: `[МАРКА]`, `[МОДЕЛЬ]`, во втором ещё `[ДАТА_НАЧАЛА]` и `[КОЛИЧЕСТВО_ДНЕЙ]`. Список авто из `data/autos.md`; в окне — уникальные пары марка + модель.

### Поиск ссылок (`data/links.md`)

Целый файл — шаблон. Плейсхолдеры: `[МАРКА]`, `[МОДЕЛЬ]`. Список авто из `data/autos.md`; в окне — уникальные пары марка + модель.

## Частые проблемы

Подробный разбор с командами — в [RUNBOOK.md, раздел 5](RUNBOOK.md#5-проблемы-и-решения). Кратко:

| Симптом | Что сделать |
|---------|-------------|
| `command not found: python` | `source .venv/bin/activate` или `python3`. На macOS команды `python` часто нет, пока не включён venv. |
| `pip: bad interpreter` / нет `/opt/homebrew/opt/python@3.11` | Старый `.venv` мёртв. Удалить и создать заново. Ставить пакеты только через `python -m pip`. |
| `No module named '_tkinter'` | Homebrew Python без Tcl/Tk. Venv на python.org 3.11 **или** `brew install python-tk@…` под вашу версию. |
| Кнопки в окне не нажимаются, помогает только свернуть | Известная связка Tk + CustomTkinter на macOS. Закрыть GUI (`Ctrl+C`), запустить снова, кликнуть заголовок окна, потом кнопку. Не использовать «окно поверх всех». См. [RUNBOOK 5.4](RUNBOOK.md#54-кнопки-в-окне-не-нажимаются-нужно-сворачивать-окно). |
| `Ошибка загрузки данных` | Формат файлов в `data/`, заголовков промптов или пустые `links.md` / `horoscope_*.md`. |
| `pbcopy не найдена` | Нужна macOS. |
| Меню терминала без стрелок | Обычный интерактивный терминал, не пайп. |
| Промпт в GUI «сам» не в буфере | Так и задумано: только кнопка **Скопировать в буфер**. |
| Нет `.venv` после clone | Окружение в git не входит — создать по быстрому старту. |

Чеклист «окно не стартует»: [RUNBOOK, раздел 6](RUNBOOK.md#6-чеклист-gui-не-стартует).
