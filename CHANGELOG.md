# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] — 2026-08-14

### Breaking

- Шаблоны перенесены из корня репозитория в `data/`.
- Файлы гороскопа переименованы: `horoscop_*.md` → `data/horoscope_*.md`.
- Образцы таблиц перенесены в `docs/samples/`.
- Пакет терминальных меню: `prompt_builder.ui` → `prompt_builder.cli`.

### Added

- Единый модуль путей `prompt_builder/paths.py`.
- Общие GUI-виджеты: выбор авто, превью промпта, карточка режима.
- В превью текст можно выделять; после копирования кнопка показывает «Скопировано».
- Календарь гороскопа: кнопка «Сегодня».
- Проверка таблиц: «Пропустить», «Назад», «К результатам».
- Дымовые тесты (`python -m unittest discover -s tests`).
- `CHANGELOG.md`, `CONTRIBUTING.md`, правила Cursor в `.cursor/rules/`.

### Changed

- Подписи режимов в GUI совпадают с терминалом (`WORK_MODE_LABELS`).
- Кнопка «На главную» скрыта на домашнем экране.
- Карточки на главной кликаются целиком; копирование в буфер только по кнопке.

## [0.1.0] — 2026-08-13

Первая версия: терминал и окно, ремонт / тюнинг / гороскоп, проверка `summary`.
